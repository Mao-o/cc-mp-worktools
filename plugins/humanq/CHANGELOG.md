# Changelog

## 0.2.0

**初版 (この marketplace での最初の公開)。** 0.1.x は公開前の試作で、配布していない。サーバーの入れ替えは版の大小で決めるため、試作の版より大きい 0.2.0 から始める。

### できること

- bd (beads) の判断待ち (`human` ラベル) を、端末の全プロジェクト分まとめて `http://127.0.0.1:8765/` の画面に出す。問いは metadata の `humanq` (問い・背景・選択肢・推奨) から描き、無いチケットは本文と自由記述欄だけを出す
- 画面で答えると、`[humanq] 回答: <label> (<key>)` のコメント (作者 `user/humanq`) を書き、`human` を `answered` に付け替える。close はしない。反映前なら取り消せる
- SessionStart: cwd から上に `.beads/` があるプロジェクトだけを登録し、サーバーが無ければ切り離して起動する。複数のセッションが同時に起動しても 1 台になる。判断待ちと回答済みの件数を Claude に伝える
- UserPromptSubmit: そのセッションで前に伝えた後の新しい回答を Claude に伝える (サーバーのキャッシュを見るだけで bd は読まない)

### 画面の動き

- 「回答する」を押すとすぐにカードを畳み、送信は裏で行う。失敗したら読み直してから戻すかを決め、書き込まれていなければ赤い枠で戻す。ほかで回答済みなら戻さない
- 描き直しはカードを key ごとに使い回す。押している最中のボタン・フォーカス・開いた本文・入力中の下書きを作り直さない。入力中のカードの更新は後回しにし、問いが変わっていれば送る前に作り直して知らせる
- 下書きは再読み込みしても残る (sessionStorage)。reduced-motion では動きを止め、失敗の目印は静的な枠で残す

### 書き込みの安全

- 待ち受けは 127.0.0.1 だけ。書き込みは、画面に埋め込んだトークンと Host の検査を通ったものだけ。CSP で外部の読み込みを禁じ、`frame-ancestors 'none'` と `X-Frame-Options: DENY` で他のサイトの iframe に入れさせない
- トークンは state dir のファイル (0600) に保存し、サーバーを入れ替えても変えない
- 送り直しで回答を二重に書かない (最後のコメントが同じ本文の `[humanq]` で 10 分以内なら、ラベルだけ直す)。ラベルの付け替えは 1 回だけ再試行し、失敗した段階と送信の種類を応答に入れる
- 見ていた問いの署名 (`qsig`) を回答に付け、問いが書き換わっていれば書き込まずに 409 を返す
- `human` と `answered` が両方付いたチケットは、最後の `[humanq]` コメントで判断待ちか回答済みかを決める。担当中 (`in_progress`) などのチケットも回答済みの一覧に出す
